HealthDiary Support

Praktische Hilfe zum Sichern, Wiederherstellen und Löschen Ihrer Informationen.

Support kontaktieren

Senden Sie uns keine medizinischen Unterlagen, Passwörter oder Backup-Dateien, es sei denn, wir bitten ausdrücklich darum. Der Support bietet keine medizinische Beratung.

Wo werden meine Daten gespeichert?

HealthDiary speichert Ihre Einträge auf Ihrem Gerät. Importierte medizinische Originale werden ebenfalls lokal gespeichert.

Wie erstelle ich ein Backup?

Öffnen Sie Profil → Daten & Backup, wählen Sie Verschlüsseltes Backup erstellen, erstellen Sie ein starkes Passwort und speichern Sie die Datei an einem sicheren Ort.

Kann ich ein Backup wiederherstellen?

Ja. Öffnen Sie Profil → Daten & Backup, wählen Sie Backup importieren, wählen Sie Ihre .healthdiary-Datei und geben Sie bei Bedarf das Passwort ein.

Wie lösche ich meine Daten?

Öffnen Sie Profil → Daten & Backup → Alle App-Daten löschen. Dadurch werden HealthDiary-Einträge, importierte Originale und geräteinterne Sicherheitskopien dauerhaft entfernt.

Apple-Health-Berechtigungen

Sie können den Apple-Health-Zugriff jederzeit in der Health-App oder in den iOS-Einstellungen verwalten.
